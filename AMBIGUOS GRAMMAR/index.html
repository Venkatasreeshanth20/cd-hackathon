CYK start-symbol chart

Nonterminals deriving each substring

What the comparison tells you

CYK fills a chart of nonterminals that can derive each substring, then reconstructs up to two distinct parse trees from the start symbol. Two trees are a concrete ambiguity witness for the selected string. A single tree only means no second parse was found for this string, not that the whole grammar is unambiguous.
